# Jarvis — Personal hands-free design

## Mission
Voice-first phone remote. Control first, chat second.

## Pipeline
Wake → Yes sir/ma'am → STT → Normalizer → OfflineBrain rules → OnDeviceNlu → Cloud LLM → CommandExecutor

## P0
- Open apps (WA Business ≠ Messenger)
- Call / WA message
- Play on Spotify | YT Music | YouTube
- Web search
- Alarm, timer, volume, briefing

## Out of scope (v1)
Armor hall, full offline GPT, system PIN bypass
